# C3 — Crítica adversarial: superfícies públicas e de entrada

**Território:** Login (gateway + formulário), Cadastro, Recuperar senha, Termos/Privacidade, Clube público, Agendamento público, Entrar na fila, Status da fila, Área do cliente, Portfólio do profissional, `PublicBusinessHeader`.
**Método:** leitura integral do código de cada superfície + telemetria forense (`docs/ux-pro/forensics/`) + mapas M1–M4. Rubrica do §12 do SUPER-PROMPT.

---

## Nota de evidência — leia antes de qualquer achado

**1. Os screenshots deste território não representam o código em HEAD.** As capturas de `docs/ux-pro/shots/` mostram um login e um cadastro que não existem no repositório: as telas fotografadas exibem strings como "ACESSO RESTRITO", "Entrar na conta", "Eu sou:", "Nome do Estabelecimento" e "RECUPERAÇÃO" — nenhuma delas existe em nenhuma branch (`git log --all -S` retorna zero) nem no bundle atual (`dist/`, reconstruído em 02/08 10:58, *depois* das capturas de 10:19–10:35). Já a **telemetria é do código atual**: os seletores medidos batem linha a linha com a fonte (`div.min-h-screen.bg-[#0A0A0A] … button.group.relative.h-72` = `pages/Login.tsx:83,102`; `border-4.border-black` no forgot-password = `pages/ForgotPassword.tsx:49`; textos "Studio"/"Beauty salon"/"Portugal · EUR" = `pages/Register.tsx:278-279,304`). Conclusão: pixels de um build anterior (provável service worker/preview stale — ver CONHECIDO-025/029), números do código atual. **Todos os achados abaixo usam código + telemetria; `shot` é `null` em todos, declarado.** Onde o shot antigo sugeria um defeito que o código atual não tem, o achado foi descartado (ver "Descartados").

**2. A falha de captura de `login-form-beauty` é explicada pelo item 1, não pelo código.** O seletor `[data-testid="category-beauty"]` existe e está no gateway atual (`pages/Login.tsx:136`). O build fotografado é que não o tinha.

**3. Superfícies sem captura (avaliadas só por código):** `/#/book/:slug`, `/#/queue/:slug`, `/#/queue-status/:id`, `/#/minha-area/:slug`, `/#/pro/:slug` — dependem de `profiles.business_slug`, vazio no tenant de teste (limite de cobertura ligado a CONHECIDO-021; popular dado é seed, fora do escopo).

**4. `clube-publico`: a telemetria mediu o estado sem `slug`.** `hashFinal = #/clube` (sem query) → a tela medida é o early-return "Link inválido" (`pages/JoinClub.tsx:119-126`): 1 tamanho de fonte, 3 espaçamentos, 1 nó de texto. Não é tela quebrada de auditoria — é a tela mais vazia do produto, e ela é real (ver C3-004).

**5. Tema `beauty` nunca foi capturado** (tema não controlável na conta de teste). A consequência disso para as públicas é achado de código (C3-002), não de pixel.
